  حل سريع لرفع مجلد public الكبير
═══════════════════════════════════════════════════════════

❌ المشكلة: مجلد public كبير جداً ولا يمكن رفعه عبر File Manager

✅ الحل الأفضل: استخدام FileZilla أو WinSCP

═══════════════════════════════════════════════════════════
  خطوات سريعة
═══════════════════════════════════════════════════════════

1. حمّل FileZilla:
   https://filezilla-project.org/

2. افتح FileZilla وأدخل:
   Host: ftp.yourdomain.com
   Username: اسم المستخدم
   Password: كلمة المرور
   Port: 21

3. اضغط Quickconnect

4. اسحب مجلد public/ من جهازك إلى الخادم

5. انتظر حتى ينتهي الرفع

═══════════════════════════════════════════════════════════
  حل بديل: ضغط ورفع
═══════════════════════════════════════════════════════════

1. اضغط مجلد public/ إلى public.zip

2. ارفع public.zip عبر File Manager

3. على الخادم (عبر SSH):
   unzip public.zip
   rm public.zip
