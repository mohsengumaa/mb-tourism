═══════════════════════════════════════════════════════════
  قائمة الملفات والمجلدات للرفع على DreamHost
═══════════════════════════════════════════════════════════

✅ المجلدات (ارفعها كاملة):
───────────────────────────────────────────────────────────
1. app/                    - جميع ملفات التطبيق
2. components/              - المكونات
3. contexts/               - Contexts
4. lib/                    - المكتبات والأدوات
5. public/                 - الملفات العامة (الصور، CSS)
6. data/                   - ملفات JSON للبيانات
7. .next/                  - مجلد البناء (بعد npm run build)

✅ الملفات في الجذر:
───────────────────────────────────────────────────────────
1. package.json
2. package-lock.json
3. next.config.js
4. tsconfig.json
5. tailwind.config.js
6. postcss.config.js
7. .htaccess
8. .env                    (أنشئه على الخادم)

❌ لا ترفع:
───────────────────────────────────────────────────────────
- node_modules/            (سيتم تثبيته على الخادم)
- .git/                    (مجلد Git)
- *.log                    (ملفات السجلات)
- .DS_Store                (ملفات النظام)

═══════════════════════════════════════════════════════════
  خطوات الرفع
═══════════════════════════════════════════════════════════

1. على جهازك المحلي:
   npm run build

2. ارفع جميع الملفات والمجلدات المذكورة أعلاه

3. على الخادم:
   - أنشئ ملف .env
   - npm install --production
   - أعد تشغيل Node.js App

═══════════════════════════════════════════════════════════
  إعدادات DreamHost Node.js App
═══════════════════════════════════════════════════════════

- Node.js version: 18.x أو أحدث
- App directory: المسار إلى مجلد المشروع
- Startup file: server.js
- Environment Variables:
  NODE_ENV=production
  NEXT_PUBLIC_SITE_URL=https://www.mbtourism.com
