# MB Tourism - موقع حجز الفنادق في إسطنبول

موقع إلكتروني متكامل لحجز الفنادق في إسطنبول وخدمات التوصيل للمطار.

## المميزات

- 🌐 دعم اللغتين العربية والإنجليزية مع تبديل سهل
- 🏨 صفحة عرض الفنادق مع فلتر متقدم
- 📱 تصميم متجاوب يعمل على جميع الأجهزة
- 🎨 واجهة مستخدم حديثة وجذابة
- 🚗 صفحة خدمات التوصيل للمطار
- 📞 صفحة التواصل مع الشركة

## الصفحات

1. **الصفحة الرئيسية**: عرض شامل مع صور متحركة والفنادق الأكثر مبيعاً
2. **صفحة الفنادق**: فلتر دقيق وعرض جميع الفنادق
3. **صفحة تفاصيل الفندق**: صور، معلومات، وغرف مع أسعار Booking
4. **من نحن**: معلومات عن الشركة وصاحبها
5. **خدمات التوصيل**: عرض خدمات التوصيل للمطار
6. **تواصل معنا**: نموذج التواصل ومعلومات الاتصال

## التقنيات المستخدمة

- Next.js 14
- React 18
- TypeScript
- Tailwind CSS
- Swiper (للصور المتحركة)
- Framer Motion

## التثبيت والتشغيل

```bash
# تثبيت الاعتماديات
npm install

# تشغيل الموقع في وضع التطوير
npm run dev

# بناء الموقع للإنتاج
npm run build

# تشغيل الموقع بعد البناء
npm start
```

افتح [http://localhost:3000](http://localhost:3000) في المتصفح لمشاهدة الموقع.

## البنية

- `/app` - صفحات Next.js
- `/components` - المكونات القابلة لإعادة الاستخدام
- `/contexts` - Context API للغات
- `/data` - بيانات الفنادق

## ملاحظات

- يمكن تحديث بيانات الفنادق في `/data/hotels.ts`
- يمكن تخصيص الألوان في `tailwind.config.js`
- الصور حالياً من Unsplash - يمكن استبدالها بصور حقيقية
